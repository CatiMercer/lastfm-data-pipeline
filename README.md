# 🎧 Last.fm Data Pipeline

Pipeline de dades desenvolupat en Python per extreure, processar i analitzar informació musical de Last.fm.

El projecte cobreix el procés complet, des de l'obtenció de dades mitjançant **web scraping** fins a l'**anàlisi exploratòria, estadística i modelització amb Machine Learning**.

> 🚧 Repositori en procés de reorganització per a portfolio.
